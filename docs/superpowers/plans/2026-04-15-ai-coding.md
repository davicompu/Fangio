# AI Coding Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a background AI coding feature where one or two LLM raters code included articles across framework dimensions using the article PDFs as context; rater agreements are auto-applied, disagreements are queued for human review.

**Architecture:** A new `ai_coding_proposal` table holds per-rater code suggestions pending resolution. The `run_ai_coding` Tauri command drives the loop: index missing PDFs on-the-fly, call the LLM (once per rater per article), then compare results — identical codes are written directly to `coding` as `model-ai-consensus`, differing codes land in `ai_coding_proposal` until the researcher accepts or rejects them. The frontend mirrors the existing AI screening background pattern: a `useAiCoding` hook at `ArrangingStage` level, a persistent bottom banner, and an `AiCodingModal` for configuration + progress.

**Tech Stack:** Rust + SQLx + Tauri events, React + TypeScript, Framer Motion, Lucide icons, existing `suggest.rs` / `lmstudio.rs` / `pdf.rs` / `vector.rs` patterns.

```rust
/// Code a single article across multiple dimensions in one LLM call.
/// `context_text` is the concatenated first N chunks of the article's PDF.
/// Returns one `DimensionCoding` per requested dimension (may have empty suggestions
/// if the model skipped it).
#[allow(clippy::too_many_arguments)]
pub async fn code_article_for_dimensions(
    base_url: &str,
    model: &str,
    framework: &str,
    domain: &str,
    research_questions: &[&str],
    dimensions: &[(String, String)], // (name, description)
    existing_codes_by_dim: &std::collections::HashMap<String, Vec<String>>,
    title: &str,
    authors: Option<&str>,
    context_text: &str,
    api_key: Option<&str>,
) -> Result<Vec<DimensionCoding>> {
    let rqs_block = if research_questions.is_empty() {
        "(not specified)".to_string()
    } else {
        research_questions
            .iter()
            .enumerate()
            .map(|(i, q)| format!("{}. {q}", i + 1))
            .collect::<Vec<_>>()
            .join("\n")
    };

    let dims_block = dimensions
        .iter()
        .map(|(name, desc)| {
            let existing = existing_codes_by_dim.get(name.as_str())
                .filter(|v| !v.is_empty())
                .map(|v| v.iter().map(|c| format!("  - {c}")).collect::<Vec<_>>().join("\n"))
                .unwrap_or_else(|| "  (none yet — propose new ones)".to_string());
            format!("Dimension \"{name}\": {desc}\n  Existing codes:\n{existing}")
        })
        .collect::<Vec<_>>()
        .join("\n\n");

    let dim_names: Vec<&str> = dimensions.iter().map(|(n, _)| n.as_str()).collect();
    let dim_list = dim_names.join(", ");

    let context_block = if context_text.trim().is_empty() {
        "(no PDF text available)".to_string()
    } else {
        // Truncate to keep the prompt manageable (~8 000 chars)
        let truncated = if context_text.len() > 8_000 {
            &context_text[..8_000]
        } else {
            context_text
        };
        truncated.to_string()
    };

    let system = format!(
        "You are a meticulous research assistant helping a scholar code articles for a systematic \
literature review. You suggest codes — you do not make decisions. The researcher always has final say.\n\n\
Review domain: {domain}\nOrganising framework: {framework}\nResearch questions:\n{rqs_block}\n\n\
For each dimension you will suggest 1–3 short noun-phrase codes (2–5 words each). \
Reuse an existing code when it fits; only mark is_new=true when no existing code is appropriate.\n\n\
Respond ONLY with a JSON object. The keys are the exact dimension names provided. \
Each value is a JSON array of objects with keys: code (string), rationale (string, one sentence), is_new (boolean).\n\
No prose before or after the JSON."
    );

    let user = format!(
        "Dimensions to code: {dim_list}\n\n{dims_block}\n\n\
Article to code:\nTitle: {title}\nAuthors: {}\n\nFull text excerpt:\n{context_block}\n\n\
Return the JSON object now.",
        authors.unwrap_or("(not recorded)")
    );

    let messages = vec![
        ChatMessage { role: "system".into(), content: system },
        ChatMessage { role: "user".into(), content: user },
    ];

    let result = lmstudio::chat(base_url, model, &messages, Some(0.2), api_key).await?;

    let codings = parse_dimension_codings(&result.content, &dim_names)
        .ok_or_else(|| anyhow::anyhow!("could not parse dimension codings from: {}", &result.content))?;

    Ok(codings)
}

fn parse_dimension_codings(s: &str, dimensions: &[&str]) -> Option<Vec<DimensionCoding>> {
    let bytes = s.as_bytes();
    let start = bytes.iter().position(|&b| b == b'{')?;
    let mut depth = 0i32;
    let mut in_str = false;
    let mut esc = false;
    let mut end = None;
    for i in start..bytes.len() {
        let c = bytes[i];
        if esc { esc = false; continue; }
        if c == b'\\' { esc = true; continue; }
        if c == b'"' { in_str = !in_str; continue; }
        if in_str { continue; }
        if c == b'{' { depth += 1; }
        else if c == b'}' {
            depth -= 1;
            if depth == 0 { end = Some(i + 1); break; }
        }
    }
    let end = end?;
    let v: serde_json::Value = serde_json::from_str(&s[start..end]).ok()?;
    let obj = v.as_object()?;
    let mut result = Vec::new();
    for dim in dimensions {
        let suggestions = obj
            .get(*dim)
            .and_then(|arr| serde_json::from_value::<Vec<Suggestion>>(arr.clone()).ok())
            .unwrap_or_default();
        result.push(DimensionCoding {
            dimension: dim.to_string(),
            suggestions,
        });
    }
    Some(result)
}
```

```rust
        .and_then(|v| v.as_str())
        .unwrap_or("text-embedding-embeddinggemma-300m-qat")
        .to_string();

    // Reset flags from any previous run
    state.coding_paused.store(false, Ordering::SeqCst);
    state.coding_cancelled.store(false, Ordering::SeqCst);
    let paused = Arc::clone(&state.coding_paused);
    let cancelled = Arc::clone(&state.coding_cancelled);

    // Load project context for the prompt
    let project = db.get_project().await.map_err(err)?;
    let domain = project.domain.clone().unwrap_or_default();
    let framework = project.framework.clone().unwrap_or_default();
    let rqs: Vec<String> = [
        project.rq_what.clone(),
        project.rq_how.clone(),
        project.rq_where.clone(),
    ]
    .into_iter()
    .flatten()
    .collect();
    let rq_refs: Vec<&str> = rqs.iter().map(|s| s.as_str()).collect();

    // Load all framework dimensions (name + description)
    let all_dims = db.list_framework_dimensions().await.map_err(err)?;
    // Filter to only the requested dimensions
    let dims_to_code: Vec<(String, String)> = all_dims
        .iter()
        .filter(|d| args.dimensions.contains(&d.name))
        .map(|d| (d.name.clone(), d.description.clone()))
        .collect();

    if dims_to_code.is_empty() {
        return Err("No valid dimensions selected for coding.".into());
    }

    // Load all included articles
    let articles = db
        .list_articles_for_coding(0, i64::MAX)
        .await
        .map_err(err)?;
    let total = articles.len();

    let mut processed = 0usize;
    let mut consensus = 0usize;
    let mut disagreements = 0usize;
    let mut skipped_no_pdf = 0usize;
    let mut indexed = 0usize;

    for (i, article) in articles.iter().enumerate() {
        // Cancel check
        if cancelled.load(Ordering::SeqCst) {
            break;
        }
        // Pause spin-wait
        while paused.load(Ordering::SeqCst) {
            if cancelled.load(Ordering::SeqCst) {
                break;
            }
            tokio::time::sleep(tokio::time::Duration::from_millis(200)).await;
        }
        if cancelled.load(Ordering::SeqCst) {
            break;
        }

        // Check if this article has a PDF linked
        let articles_with_pdf = db.included_articles_with_pdf().await.map_err(err)?;
        let pdf_info = articles_with_pdf.iter().find(|(_, aid, _, _)| *aid == article.id);

        if pdf_info.is_none() {
            skipped_no_pdf += 1;
            let _ = app.emit(
                "coding:progress",
                AiCodingProgress {
                    done: i + 1,
                    total,
                    article_title: format!("⚠ No PDF: {}", article.title),
                    phase: "indexing".into(),
                    skipped_no_pdf,
                    consensus,
                    disagreements,
                },
            );
            continue;
        }

        let (pdf_id, _, _, stored_path) = pdf_info.unwrap();

        // Index the PDF if not yet done (chunks present = indexed)
        let chunks_exist: i64 = sqlx::query_scalar(
            "SELECT COUNT(*) FROM pdf_chunk WHERE article_id = ?",
        )
        .bind(article.id)
        .fetch_one(&db.pool)
        .await
        .map_err(err)?;

        if chunks_exist == 0 {
            let _ = app.emit(
                "coding:progress",
                AiCodingProgress {
                    done: i,
                    total,
                    article_title: article.title.clone(),
                    phase: "indexing".into(),
                    skipped_no_pdf,
                    consensus,
                    disagreements,
                },
            );

            match pdf::extract(std::path::Path::new(stored_path)) {
                Ok(extracted) => {
                    let chunks = pdf::chunk(&extracted.text);
                    let chunk_records: Vec<(i64, String)> =
                        chunks.iter().map(|c| (c.index as i64, c.text.clone())).collect();
                    db.save_pdf_chunks(*pdf_id, article.id, extracted.text.len() as i64, &chunk_records)
                        .await
                        .map_err(err)?;

                    // Embed chunks so the article can be used for chat later
                    if !embed_model.is_empty() {
                        let chunk_list = db.list_chunks_for_pdf(*pdf_id).await.map_err(err)?;
                        let batch_size = 16usize;
                        for batch in chunk_list.chunks(batch_size) {
                            let texts: Vec<&str> = batch.iter().map(|c| c.text.as_str()).collect();
                            if let Ok(embeddings) = lmstudio::embed(
                                &base_url,
                                &embed_model,
                                &texts,
                                api_key.as_deref(),
                            )
                            .await
                            {
                                for (chunk, emb) in batch.iter().zip(embeddings.iter()) {
                                    let bytes = vector::f32s_to_bytes(emb);
                                    let _ = db.save_chunk_embedding(chunk.id, &bytes, &embed_model).await;
                                }
                            }
                        }
                        let _ = db.mark_pdf_embedded(*pdf_id).await;
                    }
                    indexed += 1;
                }
                Err(e) => {
                    eprintln!("pdf extract error for article {}: {e}", article.id);
                    skipped_no_pdf += 1;
                    continue;
                }
            }
        }

        // Get first 8 chunks as context text for coding
        let chunks = db.list_chunks_for_article(article.id, 8).await.map_err(err)?;
        let context_text: String = chunks.iter().map(|c| c.text.as_str()).collect::<Vec<_>>().join("\n\n");

        // Load existing codes per dimension for this article's corpus
        let mut existing_by_dim: std::collections::HashMap<String, Vec<String>> = std::collections::HashMap::new();
        for (dim_name, _) in &dims_to_code {
            let codes = db.distinct_codes_for_dimension(dim_name).await.map_err(err)?;
            existing_by_dim.insert(dim_name.clone(), codes);
        }

        // Rater 1
        let _ = app.emit(
            "coding:progress",
            AiCodingProgress {
                done: i,
                total,
                article_title: article.title.clone(),
                phase: "coding-rater1".into(),
                skipped_no_pdf,
                consensus,
                disagreements,
            },
        );

        let rater1_result = suggest::code_article_for_dimensions(
            &base_url,
            &args.rater1_model,
            &framework,
            &domain,
            &rq_refs,
            &dims_to_code,
            &existing_by_dim,
            &article.title,
            article.authors.as_deref(),
            &context_text,
            api_key.as_deref(),
        )
        .await;

        let rater1_codings = match rater1_result {
            Ok(c) => c,
            Err(e) => {
                eprintln!("Rater 1 coding error for article {}: {e}", article.id);
                processed += 1;
                continue;
            }
        };

        // Rater 2 (optional)
        let rater2_codings: Option<Vec<suggest::DimensionCoding>> = if let Some(r2_model) = &args.rater2_model {
            let _ = app.emit(
                "coding:progress",
                AiCodingProgress {
                    done: i,
                    total,
                    article_title: article.title.clone(),
                    phase: "coding-rater2".into(),
                    skipped_no_pdf,
                    consensus,
                    disagreements,
                },
            );
            match suggest::code_article_for_dimensions(
                &base_url,
                r2_model,
                &framework,
                &domain,
                &rq_refs,
                &dims_to_code,
                &existing_by_dim,
                &article.title,
                article.authors.as_deref(),
                &context_text,
                api_key.as_deref(),
            )
            .await
            {
                Ok(c) => Some(c),
                Err(e) => {
                    eprintln!("Rater 2 coding error for article {}: {e}", article.id);
                    None
                }
            }
        } else {
            None
        };

        // Resolve: compare rater1 vs rater2 per dimension
        let _ = app.emit(
            "coding:progress",
            AiCodingProgress {
                done: i,
                total,
                article_title: article.title.clone(),
                phase: "resolving".into(),
                skipped_no_pdf,
                consensus,
                disagreements,
            },
        );

        if let Some(r2) = &rater2_codings {
            // Build lookup: dimension -> Vec<code> for each rater
            let r1_map: std::collections::HashMap<&str, Vec<&str>> = rater1_codings
                .iter()
                .map(|dc| (dc.dimension.as_str(), dc.suggestions.iter().map(|s| s.code.as_str()).collect()))
                .collect();
            let r2_map: std::collections::HashMap<&str, Vec<&str>> = r2
                .iter()
                .map(|dc| (dc.dimension.as_str(), dc.suggestions.iter().map(|s| s.code.as_str()).collect()))
                .collect();

            for r1_dim_coding in &rater1_codings {
                let dim = r1_dim_coding.dimension.as_str();
                let r2_codes = r2_map.get(dim).cloned().unwrap_or_default();

                for s in &r1_dim_coding.suggestions {
                    if r2_codes.contains(&s.code.as_str()) {
                        // Both raters agree → save as consensus
                        let _ = db.save_coding(
                            article.id,
                            dim,
                            &s.code,
                            s.rationale.as_deref(),
                            "model-ai-consensus",
                            Some(&args.rater1_model),
                        ).await;
                        consensus += 1;
                    } else {
                        // Rater 1 only → save as proposal
                        let _ = db.save_ai_coding_proposal(
                            article.id,
                            dim,
                            &s.code,
                            s.rationale.as_deref(),
                            1,
                            Some(&args.rater1_model),
                            &args.run_id,
                        ).await;
                        disagreements += 1;
                    }
                }

                // Rater 2 codes that rater 1 didn't suggest
                if let Some(r2_dim_coding) = r2.iter().find(|dc| dc.dimension == dim) {
                    let r1_codes = r1_map.get(dim).cloned().unwrap_or_default();
                    for s in &r2_dim_coding.suggestions {
                        if !r1_codes.contains(&s.code.as_str()) {
                            let _ = db.save_ai_coding_proposal(
                                article.id,
                                dim,
                                &s.code,
                                s.rationale.as_deref(),
                                2,
                                args.rater2_model.as_deref(),
                                &args.run_id,
                            ).await;
                            // Don't double-count disagreements (already counted above)
                        }
                    }
                }
            }
        } else {
            // Single rater → apply all directly as consensus
            for dim_coding in &rater1_codings {
                for s in &dim_coding.suggestions {
                    let _ = db.save_coding(
                        article.id,
                        &dim_coding.dimension,
                        &s.code,
                        s.rationale.as_deref(),
                        "model-ai-consensus",
                        Some(&args.rater1_model),
                    ).await;
                    consensus += 1;
                }
            }
        }

        processed += 1;
    }

    Ok(AiCodingResult {
        processed,
        consensus,
        disagreements,
        skipped_no_pdf,
        indexed,
    })
}
```

```typescript
import { useCallback, useState } from "react";
import { listen } from "@tauri-apps/api/event";
import { api, type AiCodingProgress, type AiCodingResult } from "../lib/api";

export interface AiCodingHook {
  step: "idle" | "running" | "done" | "error";
  progress: AiCodingProgress | null;
  result: AiCodingResult | null;
  error: string | null;
  isPaused: boolean;
  start: (args: { rater1Model: string; rater2Model: string | null; dimensions: string[] }) => Promise<void>;
  pause: () => Promise<void>;
  resume: () => Promise<void>;
  cancel: () => Promise<void>;
  reset: () => void;
}

export function useAiCoding(): AiCodingHook {
  const [step, setStep] = useState<"idle" | "running" | "done" | "error">("idle");
  const [progress, setProgress] = useState<AiCodingProgress | null>(null);
  const [result, setResult] = useState<AiCodingResult | null>(null);
  const [error, setError] = useState<string | null>(null);
  const [isPaused, setIsPaused] = useState(false);

  const start = useCallback(
    async (args: { rater1Model: string; rater2Model: string | null; dimensions: string[] }) => {
      setStep("running");
      setProgress(null);
      setResult(null);
      setError(null);
      setIsPaused(false);
      const runId = crypto.randomUUID();

      const unlisten = await listen<AiCodingProgress>("coding:progress", (event) => {
        setProgress(event.payload);
      });

      try {
        const r = await api.runAiCoding({
          rater1_model: args.rater1Model,
          rater2_model: args.rater2Model,
          dimensions: args.dimensions,
          run_id: runId,
        });
        setResult(r);
        setStep("done");
      } catch (e: any) {
        setError(e?.message ?? String(e));
        setStep("error");
      } finally {
        unlisten();
      }
    },
    [],
  );

  const pause = useCallback(async () => {
    setIsPaused(true);
    await api.pauseAiCoding();
  }, []);

  const resume = useCallback(async () => {
    setIsPaused(false);
    await api.resumeAiCoding();
  }, []);

  const cancel = useCallback(async () => {
    await api.cancelAiCoding();
  }, []);

  const reset = useCallback(() => {
    setStep("idle");
    setProgress(null);
    setResult(null);
    setError(null);
    setIsPaused(false);
  }, []);

  return { step, progress, result, error, isPaused, start, pause, resume, cancel, reset };
}
```
